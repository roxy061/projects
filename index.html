SYSTEM COMPLIANCE REQUIREMENT

ข้อกำหนดองค์ประกอบโปรเจกต์

มาตรฐานการจัดเตรียมระบบเซิร์ฟเวอร์และโครงสร้างเว็บแอปพลิเคชัน สำหรับนักศึกษาแผนกเทคโนโลยีสารสนเทศ

1. โครงสร้างเว็บและโดเมน

Web & VirtualHost Configuration

REQ-01
  • ตั้งค่าชื่อโดเมน/Subdomain ประจำตัว เช่น std66001.nvc.ac.th
  • สร้างและเปิดใช้งานไฟล์ VirtualHost ใน Nginx ที่ตำแหน่ง /etc/nginx/conf.d/username.conf
/etc/nginx/conf.d/std66001.conf 
server {
    listen 80;
    server_name std66001.nvc.ac.th;
    root /var/www/std66001;
    index index.html index.php;
}

2. ระบบเว็บไซต์และฐานข้อมูล

Web Application & MariaDB

REQ-02
  • เว็บไซต์มีการดึงข้อมูลแสดงผลจาก MariaDB Database (คลังสินค้า, บันทึกงาน หรือคลังโปรเจกต์)
  • มีการสร้าง User & Password เฉพาะใน MariaDB สำหรับการเชื่อมต่อของเว็บตนเอง (ห้ามใช้ root)
MariaDB SQL Setup Command 
CREATE DATABASE db_std66001;
CREATE USER 'user_std66001'@'localhost' IDENTIFIED BY 'StrongPass!';
GRANT ALL PRIVILEGES ON db_std66001.* TO 'user_std66001'@'localhost';

3. ความปลอดภัยและไฟร์วอลล์

Security & HTTPS (Port 443 SSL)

REQ-03
  • หน้าเว็บเปิดใช้งาน SSL/HTTPS มีสัญลักษณ์แม่กุญแจความปลอดภัย 🔒 บน URL (พอร์ต 443 SSL Cert)
  • ไฟร์วอลล์ UFW เปิดทำงาน อนุญาตเฉพาะพอร์ตที่จำเป็น เช่น พอร์ต 22 (SSH), 80 (HTTP), 443 (HTTPS)
UFW Firewall Setup 
# อนุญาตเฉพาะพอร์ตที่จำเป็นเท่านั้น
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

4. ระบบสำรองข้อมูลและการดู Log

Backup & Observability

REQ-04
  • มีไฟล์สำรองข้อมูลฐานข้อมูลอัตโนมัติไฟล์ .sql.gz เก็บอยู่ในโฟลเดอร์ /var/backups/username/
  • ตั้งค่าคำสั่ง Crontab สำหรับสำรองข้อมูลอัตโนมัติเรียบร้อยแล้ว
Crontab Backup Job (crontab -e) 
# สำรองข้อมูลอัตโนมัติทุกตี 2
0 2 * * * mysqldump -u user_std66001 -p'pass' db_std66001 | gzip > /var/backups/std66001/backup_$(date +\%Y\%m\%d).sql.gz
