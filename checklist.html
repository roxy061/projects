ข้อกำหนดองค์ประกอบเซิร์ฟเวอร์

รายละเอียดมาตรฐานและสคริปต์คำสั่งการติดตั้งระบบเซิร์ฟเวอร์ Nginx, MariaDB, UFW Firewall และ Crontab แบ็กอัป

🌐 1. โครงสร้างเว็บและโดเมน

Web & VirtualHost Configuration

  • ตั้งค่า Subdomain ประจำตัว เช่น username.nvc.ac.th
  • เปิดใช้งานไฟล์ VirtualHost ใน Nginx ที่ตำแหน่ง /etc/nginx/conf.d/username.conf
/etc/nginx/conf.d/std66001.conf 
server {
    listen 80;
    server_name std66001.nvc.ac.th;
    root /var/www/std66001;
    index index.html index.php;
}

💾 2. ระบบเว็บไซต์และฐานข้อมูล

Web Application & MariaDB

  • เว็บไซต์มีการเชื่อมต่อและแสดงผลจาก MariaDB Database
  • สร้าง DB User & Password เฉพาะการใช้งานของตนเอง (ห้ามใช้ root)
MariaDB SQL User Setup 
CREATE DATABASE projects_db;
CREATE USER 'user_std66001'@'localhost' IDENTIFIED BY 'StrongPass!';
GRANT ALL PRIVILEGES ON projects_db.* TO 'user_std66001'@'localhost';

🔒 3. ความปลอดภัยและไฟร์วอลล์

Security & HTTPS (Port 443 SSL)

  • หน้าเว็บเปิดใช้งาน SSL/HTTPS มีสัญลักษณ์ 🔒 บน URL (พอร์ต 443)
  • ตั้งค่า UFW Firewall เปิดเฉพาะพอร์ตจำเป็น (22, 80, 443)
UFW Firewall Setup 
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

⏰ 4. สำรองข้อมูลและการดู Log

Backup & Observability

  • เก็บไฟล์สำรองฐานข้อมูลอัตโนมัติ .sql.gz ไว้ที่ /var/backups/username/
  • ตั้งค่าคำสั่ง Crontab สำรองข้อมูลตามเวลาที่กำหนด
Crontab Backup Job (crontab -e) 
0 0 * * * mysqldump -u user_std66001 -p'pass' projects_db | gzip > /var/backups/std66001/backup.sql.gz
